# Car Mod

Fabric 载具模组，对应 Minecraft 26.2。客户端和服务端都要装，还需要 Fabric API 和 Java 25。

源码：https://github.com/LaVendergong/carmod
问题：https://github.com/LaVendergong/carmod/issues

## 共用操作

对方块右键放置。对载具右键上车。Shift 下车。攻击收回。

## 地面载具

- 汽车：WASD 驾驶。
- 铲车：按 B 放下或升起铲斗。放下后向前开，会铲平前方五格高的路面。
- 自卸车：开车时吸走周围掉落物。按 V 卸货，车尾对着箱子就倒进去，否则卸在车后。
- 钻地车：按 G 切换 15°、30°、45° 或垂直向下。按住前进打地道，倒车沿原路退出。
- 水陆两栖车：陆地和水上都能开，可以从岸边下水，也可以从水里上岸。
- 赛车：比汽车快。按住空格再转向可以漂移。

## 飞行

直升机要等旋翼转到飞行转速才能离地。W 前进，A D 转向，空格上升，Ctrl 下降，松开就悬停。撞墙，或者飞得很快时撞上东西，会爆炸。

武装直升机飞法相同。按 R 锁定前方地面上的生物并发射导弹。普通直升机没有导弹。

战斗机的油门会停在松开的位置。空格加油，Ctrl 收油。地面上 A D 转向，速度够了按 S 拉起。升空后 W 压头，S 抬头，按住 A 或 D 可以滚到倒飞，松手就停在当前姿态。人和视角都锁在机身上。飞太慢会失速。按住 X 打机炮，R 发射导弹。撞墙、砸地或入水会爆炸。

## 核弹

对方块右键放置。走开后按 N，引爆同一维度里你放置的最近一颗，爆炸半径 64 格。攻击可以收回。合成是 4 个 TNT 加 1 颗末影珍珠。

## 道路

沥青、白线、斑马线、红绿灯。铺路器放在箱子前面，收到红石信号后向前铺路。盾构器贴在铺路器前方或侧面，朝向相同，会挖掉正前方的方块并收进后方箱子。
